# @airnest/postgres

PostgreSQL storage for [airnest](https://github.com/tqrcisio/airnest): migrations, runs, a task queue with
`FOR UPDATE SKIP LOCKED`, leases and a reaper, retries, pools, outputs, logs and retention. Works with `pg` through
`fromPgPool(pool)` and with PGlite directly.

Documentation: https://tqrcisio.github.io/airnest-docs/reference/database-schema/
