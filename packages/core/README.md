# @airnest/core

The framework-free engine behind [airnest](https://github.com/tqrcisio/airnest): DAG validation, Airflow's trigger rules,
run planning, retry delays, params validation and cron timetables with logical dates and data intervals.

Most applications use it through [`@airnest/nestjs`](https://www.npmjs.com/package/@airnest/nestjs).
Documentation: https://tqrcisio.github.io/airnest-docs
